# Release Notes

## Preview Release 8.1.0-preview1

`Microsoft.Data.SqlClient.Extensions.Azure` aligns with the `8.1.0-preview1` driver.
See the [core release notes](../../../8.1/8.1.0-preview1.md).
The family `AssemblyVersion` remains `8.0.0.0`; upgrading from 8.0 does not change
.NET Framework strong-name binding.

### Changed

- Updated Azure.Core from `1.63.0` to `1.65.0`, MSAL and its broker from `4.91.1` to `4.92.0`,
  and cryptography/caching dependency floors from `10.0.13` to `10.0.15`. Family dependencies
  align to `8.1.0-preview1`. There are no additional functional or public API changes to this
  package since [8.0.0-preview1](../8.0/8.0.0-preview1.md).
  ([#5031](https://github.com/dotnet/SqlClient/pull/5031))

## Target Platform Support

- Package assets: .NET Framework 4.6.2 and .NET Standard 2.0.
- With the 8.1 driver: .NET Framework 4.6.2+ on Windows, or .NET 10.0+ on Windows, Linux, and macOS.
