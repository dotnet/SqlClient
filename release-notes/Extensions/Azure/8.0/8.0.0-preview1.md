# Release Notes

## Preview Release 8.0.0-preview1 - Unreleased

This is a review snapshot of `Microsoft.Data.SqlClient.Extensions.Azure`, not a release
announcement. The source cutoff, pending release details, and family version alignment are
documented in the [core driver notes](../../../8.0/8.0.0-preview1.md).
Changes below are relative to [7.1.1](../7.1/7.1.1.md).

### Added

#### Azure Attestation token validation

*What Changed:*

- Azure Attestation token validation moved from the core driver into this extension, together
  with its IdentityModel dependencies.
  ([#4790](https://github.com/dotnet/SqlClient/pull/4790))

*Who Benefits:*

- Applications not using Azure Attestation can avoid these dependencies in the core driver.

*Impact:*

- Applications using Always Encrypted with `Attestation Protocol=AAS` must now reference this
  package explicitly, at the same version as the driver. Without it, enclave session setup
  throws `InvalidOperationException`. The enclave provider itself remains in the core driver.

### Changed

#### Azure.Core credential dependency migration

*What Changed:*

- Replaced the separate Azure.Identity dependency with Azure.Core, which supplies the credential
  types. The `Azure.Identity` namespace and public credential APIs are unchanged.
  ([#4749](https://github.com/dotnet/SqlClient/pull/4749))

*Who Benefits:*

- Applications adopting the consolidated Azure SDK credential dependency.

*Impact:*

- Remove an explicit Azure.Identity reference older than 1.21.0, or upgrade it to 1.21.0 or later
  to avoid duplicate-type errors. If an older version arrives transitively, add a direct
  reference to the newer forwarding package. Azure.Identity.Broker users need 1.6.0 or later.

#### Other changes

- Updated Azure.Core, MSAL, MSAL Broker, and caching dependencies to the versions below.
  ([#4880](https://github.com/dotnet/SqlClient/pull/4880))
- This package aligns with the 8.0 driver family, including the final preview build suffix.
  `AssemblyVersion` changes from `7.0.0.0` to `8.0.0.0`; review .NET Framework binding redirects.

## Target Platform Support

- .NET Framework 4.6.2 (`net462`).
- .NET Standard 2.0 (`netstandard2.0`).
- When used with the 8.0 driver, supported runtimes are .NET Framework 4.6.2+ on Windows
  and .NET 10.0+ on Windows, Linux, and macOS. The Standard target does not extend driver support.
