# Release Notes

## Stable Release 7.1.1 - 2026-09-29

This release aligns `Microsoft.Data.SqlClient.Extensions.Azure` with the core `Microsoft.Data.SqlClient` driver version (`7.1.1`). There are no functional or API changes. See the core [Microsoft.Data.SqlClient 7.1.1](../../../7.1/7.1.1.md) release notes for the driver-family changes shipped alongside this version.

> **Version alignment:** This package continues to track the core driver version. The assembly ships with `FileVersion 7.1.1.x` and retains `AssemblyVersion 7.0.0.0`, so upgrading from `7.1.0` does not require new .NET Framework strong-name binding redirects.

## Changes Since [7.1.0](7.1.0.md)

There are no functional or API changes in this release.

## Cumulative Changes Since [7.0.3](../7.0/7.0.3.md)

There are no additional cumulative changes since [7.0.3](../7.0/7.0.3.md).
