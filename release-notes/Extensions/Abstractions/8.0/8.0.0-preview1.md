# Release Notes

## Preview Release 8.0.0-preview1 - Unreleased

This is a review snapshot of `Microsoft.Data.SqlClient.Extensions.Abstractions`, not a release
announcement. The source cutoff, pending release details, and family version alignment are
documented in the [core driver notes](../../../8.0/8.0.0-preview1.md).
Changes below are relative to [7.1.1](../7.1/7.1.1.md).

### Added

#### Public authentication configuration handlers

*What Changed:*

- Exposed `Microsoft.Data.SqlClient.SqlAuthenticationProviderConfigurationSection` and
  `Microsoft.Data.SqlClient.SqlClientAuthenticationProviderConfigurationSection` from
  Abstractions. These formerly internal driver types are public configuration infrastructure
  and hidden from IntelliSense with `EditorBrowsableState.Never`.
  ([#4816](https://github.com/dotnet/SqlClient/pull/4816))

*Who Benefits:*

- Applications and configuration tooling using the current or legacy authentication
  configuration section schema.

*Impact:*

- Type forwards preserve existing driver-qualified app.config declarations, section names,
  properties, and empty defaults. This change does not introduce stricter configuration loading
  or move runtime provider activation into a new registry; those follow-ups are not merged.
- ConfigurationManager is exposed as a transitive compile dependency for the .NET Standard
  target. A `net462` target uses the .NET Framework `System.Configuration` assembly.

### Changed

- This package aligns with the 8.0 driver family, including the final preview build suffix.
  `AssemblyVersion` changes from `7.0.0.0` to `8.0.0.0`; review .NET Framework binding redirects.

## Target Platform Support

- .NET Framework 4.6.2 (`net462`).
- .NET Standard 2.0 (`netstandard2.0`).
- When used with the 8.0 driver, supported runtimes are .NET Framework 4.6.2+ on Windows
  and .NET 10.0+ on Windows, Linux, and macOS. The Standard target does not extend driver support.
