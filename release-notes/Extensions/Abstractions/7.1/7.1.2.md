# Release Notes

## Stable Release 7.1.2 - 2026-11-12

This release aligns `Microsoft.Data.SqlClient.Extensions.Abstractions` with the core
driver version `7.1.2`. There are no functional or API changes.
See the core [Microsoft.Data.SqlClient 7.1.2](../../../7.1/7.1.2.md) release notes
for the driver-family changes shipped alongside this version.

The assembly retains `AssemblyVersion 7.0.0.0`; upgrading from `7.1.1` does not require
new .NET Framework strong-name binding redirects.
