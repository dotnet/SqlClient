# Release Notes

## Preview Release 8.1.0-preview1

`Microsoft.Data.SqlClient.Internal.Logging` aligns with the `8.1.0-preview1` driver.
See the [core release notes](../../../8.1/8.1.0-preview1.md).

> **Internal use only:** This package supports other SqlClient packages. Applications should
> not reference it directly. The family `AssemblyVersion` remains `8.0.0.0`; upgrading from
> 8.0 does not change .NET Framework strong-name binding.

### Changed

- Version alignment only: there are no functional or public API changes to this package
  since [8.0.0-preview1](../8.0/8.0.0-preview1.md). The package version changes to match
  `Microsoft.Data.SqlClient 8.1.0-preview1`.

## Target Platform Support

- Package asset: .NET Standard 2.0.
- Used by the 8.1 family on .NET Framework 4.6.2+ on Windows and .NET 10.0+ on Windows, Linux,
  and macOS.

### Dependencies

#### .NET Standard 2.0

No direct NuGet dependencies.
