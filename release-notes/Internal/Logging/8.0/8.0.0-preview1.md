# Release Notes

## Preview Release 8.0.0-preview1 - Unreleased

> **Note:** This package is for internal use by other Microsoft.Data.SqlClient packages only
> and should not be referenced directly by application code.

This is a review snapshot, not a release announcement. The source cutoff, pending release
details, and family version alignment are documented in the
[core driver notes](../../../8.0/8.0.0-preview1.md).
Changes below are relative to [7.1.1](../7.1/7.1.1.md).

### Changed

- Added targeted trimming annotations for the `BeginExecute` and `EndExecute` EventSource
  paths, whose payloads contain primitive values. Event payloads and public APIs are unchanged.
  This reduces warnings when trimming modern .NET applications; it does not establish complete
  Native AOT support.
  ([#4703](https://github.com/dotnet/SqlClient/pull/4703))
- This package aligns with the 8.0 driver family, including the final preview build suffix.
  `AssemblyVersion` changes from `7.0.0.0` to `8.0.0.0`; review .NET Framework binding redirects.
