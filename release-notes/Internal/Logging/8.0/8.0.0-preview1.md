# Release Notes

## Preview Release 8.0.0-preview1 - Unreleased

Draft for `Microsoft.Data.SqlClient.Internal.Logging`, aligned with the driver package version
and preview build suffix. See the [core release notes](../../../8.0/8.0.0-preview1.md)
for the source cutoff, branch-cut baseline, and complete scope.

> **Internal use only:** This package supports other SqlClient packages. Applications should
> not reference it directly. The family `AssemblyVersion` changes to `8.0.0.0`;
> .NET Framework consumers should review strong-name binding redirects.

### Added

#### Authentication EventSource events

*What Changed:*

- Added `AuthenticationTrace` (`0x2000`) and authentication event IDs 22-27 to
  `Microsoft.Data.SqlClient.EventSource`, carrying message, source, and connection ID.
  ([#4872](https://github.com/dotnet/SqlClient/pull/4872))

*Who Benefits:*

- Collectors can isolate authentication diagnostics emitted by the Azure extension.

*Impact:*

- Existing ordinary tracing masks do not automatically include authentication.
  Use `0x2000` for authentication only or `0x2002` for authentication and ordinary trace.
  See the [Azure extension notes](../../../Extensions/Azure/8.0/8.0.0-preview1.md)
  for privacy, correlation, and collection limitations.

### Changed

- Added targeted trimming annotations for `BeginExecute`/`EndExecute` primitive event
  payloads, avoiding unnecessary IL2026 warnings when trimming modern .NET applications.
  Event payloads are unchanged; this does not establish full Native AOT support.
  ([#4703](https://github.com/dotnet/SqlClient/pull/4703))
