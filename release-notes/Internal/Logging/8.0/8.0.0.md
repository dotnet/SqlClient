# Release Notes

## Stable Release 8.0.0

`Microsoft.Data.SqlClient.Internal.Logging` aligns with the `8.0.0` driver.
See the [core release notes](../../../8.0/8.0.0.md).

> **Internal use only:** This package supports other SqlClient packages. Applications should
> not reference it directly. The family `AssemblyVersion` is `8.0.0.0`: unchanged from preview1,
> but changed from `7.0.0.0` in 7.x. .NET Framework consumers upgrading from 7.x should review
> strong-name binding redirects.

## Changes Since [8.0.0-preview1](8.0.0-preview1.md)

### Changed

- Version alignment only: there are no additional functional or public API changes to this package
  since preview1. The package version changes to match `Microsoft.Data.SqlClient 8.0.0`.

## Cumulative Changes Since [7.1.2](../7.1/7.1.2.md)

The cumulative view includes the alignment delta above and these preview1 changes:

### Added

#### Authentication EventSource events

*What Changed:*

- Added `AuthenticationTrace` (`0x2000`) and authentication event IDs 22-27 with message, source,
  and connection ID payloads.
  ([#4872](https://github.com/dotnet/SqlClient/pull/4872))

*Who Benefits:*

- Diagnostic collectors can isolate authentication activity from the Azure extension.

*Impact:*

- Ordinary trace masks do not automatically include authentication. Use `0x2000`, or `0x2002`
  with ordinary tracing. See the [Azure extension notes](../../../Extensions/Azure/8.0/8.0.0.md)
  for privacy, correlation, and collection limitations.

### Changed

- Targeted trimming annotations for `BeginExecute`/`EndExecute` primitive event payloads avoid
  unnecessary IL2026 warnings when trimming modern .NET applications. Payloads are unchanged;
  this does not establish full Native AOT support. (modern .NET only)
  ([#4703](https://github.com/dotnet/SqlClient/pull/4703))
