# Release Notes

## Stable Release 7.0.4 - 2026-11-12

This release aligns `Microsoft.Data.SqlClient.AlwaysEncrypted.AzureKeyVaultProvider` with the
core driver version `7.0.4`. There are no functional or API changes.
See the core [Microsoft.Data.SqlClient 7.0.4](../../../7.0/7.0.4.md) release notes
for the driver-family changes shipped alongside this version.

The assembly retains `AssemblyVersion 7.0.0.0`; upgrading from `7.0.3` does not require
new .NET Framework strong-name binding redirects.
