# Release Notes

## Planned Stable Release 8.0.0 - Unreleased

`Microsoft.Data.SqlClient.AlwaysEncrypted.AzureKeyVaultProvider` is planned to align with the
`8.0.0` driver. This release has not been published. See the
[core release notes](../../../8.0/8.0.0.md).
The family `AssemblyVersion` is `8.0.0.0`: unchanged from preview1, but changed from `7.0.0.0`
in the 7.x family. .NET Framework consumers upgrading from 7.x should review binding redirects.

## Changes Since [8.0.0-preview1](8.0.0-preview1.md)

### Changed

- Updated Azure.Core from `1.63.0` to `1.65.0` and caching from `10.0.13` to `10.0.15`.
  The Key Vault Keys SDK remains `4.10.2`; driver and Logging dependencies align to `8.0.0`.
  There are no additional functional or public API changes to the key-store provider.
  ([#5031](https://github.com/dotnet/SqlClient/pull/5031),
  [#5041](https://github.com/dotnet/SqlClient/pull/5041))

## Cumulative Changes Since [7.1.2](../7.1/7.1.2.md)

The cumulative view includes the dependency delta above and preview1's dependency transition.

### Changed

#### Azure SDK dependencies and version alignment

*What Changed:*

- Updated Azure.Core, caching, and Key Vault Keys SDK minimums to the versions below.
  This is a dependency-update release, not a new key-store API release.
  ([#4749](https://github.com/dotnet/SqlClient/pull/4749),
  [#4880](https://github.com/dotnet/SqlClient/pull/4880))

*Who Benefits:*

- Always Encrypted applications using Azure Key Vault receive the updated Azure SDK dependencies.

*Impact:*

- Azure.Core now supplies Azure.Identity credential types. Remove older direct Azure.Identity
  references or upgrade to 1.21.0+; Azure.Identity.Broker users need 1.6.0+.
- Use matching versions of the driver and companion packages. Existing async provider APIs
  remain available for direct use, but driver key-store resolution remains synchronous for
  both synchronous and asynchronous commands.

## Target Platform Support

- Package asset: .NET Standard 2.0.
- With the 8.0 driver: .NET Framework 4.6.2+ on Windows, or .NET 10.0+ on Windows, Linux, and macOS.
