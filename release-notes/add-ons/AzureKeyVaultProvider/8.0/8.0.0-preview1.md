# Release Notes

## Preview Release 8.0.0-preview1 - Unreleased

This is a review snapshot of `Microsoft.Data.SqlClient.AlwaysEncrypted.AzureKeyVaultProvider`,
not a release announcement. The source cutoff, pending release details, and family version
alignment are documented in the [core driver notes](../../../8.0/8.0.0-preview1.md).
Changes below are relative to [7.1.1](../7.1/7.1.1.md).

### Changed

- The updated Azure.Core dependency now supplies credential types in the `Azure.Identity`
  namespace. Applications explicitly referencing Azure.Identity older than
  1.21.0 must remove that reference or upgrade to 1.21.0 or later to avoid duplicate-type errors;
  Azure.Identity.Broker users need 1.6.0 or later.
  The provider already depended on Azure.Core; this is guidance for consumers of the newer
  dependency, not a new credential API in this package.
  ([#4749](https://github.com/dotnet/SqlClient/pull/4749), [#4880](https://github.com/dotnet/SqlClient/pull/4880))
- Updated Azure.Core to 1.63.0, Azure.Security.KeyVault.Keys to 4.10.2, and
  Microsoft.Extensions.Caching.Memory to 10.0.13.
  ([#4779](https://github.com/dotnet/SqlClient/pull/4779), [#4880](https://github.com/dotnet/SqlClient/pull/4880))
- This package aligns with the 8.0 driver family, including the final preview build suffix.
  `AssemblyVersion` changes from `7.0.0.0` to `8.0.0.0`; review .NET Framework binding redirects.
  There are no new public provider APIs in this snapshot.

## Target Platform Support

- .NET Standard 2.0 (`netstandard2.0`).
- When used with the 8.0 driver, supported runtimes are .NET Framework 4.6.2+ on Windows
  and .NET 10.0+ on Windows, Linux, and macOS. The Standard target does not extend driver support.
