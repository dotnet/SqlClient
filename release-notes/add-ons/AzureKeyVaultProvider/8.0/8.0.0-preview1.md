# Release Notes

## Preview Release 8.0.0-preview1 - Unreleased

Draft for `Microsoft.Data.SqlClient.AlwaysEncrypted.AzureKeyVaultProvider`, aligned with the
driver package version and preview build suffix. See the
[core release notes](../../../8.0/8.0.0-preview1.md) for the source cutoff, branch-cut baseline,
and complete scope. This is a dependency-update release, not a new key-store API release.

The family `AssemblyVersion` changes from `7.0.0.0` to `8.0.0.0`. .NET Framework applications
should review strong-name binding redirects and use matching versions of the driver and all
installed companion packages.

### Changed

#### Dependency updates and version alignment

*What Changed:*

- Updated the shared Azure.Core and caching dependency floors and the Key Vault Keys SDK.
  Use the matching 8.0.0-preview1 driver and internal logging packages.
  ([#4749](https://github.com/dotnet/SqlClient/pull/4749),
  [#4880](https://github.com/dotnet/SqlClient/pull/4880))

*Who Benefits:*

- Applications using Azure Key Vault for Always Encrypted receive the updated Azure SDK
  and dependency servicing band.

*Impact:*

- No new key-store provider methods or behavioral changes are introduced in this snapshot.
- Azure.Core now supplies Azure.Identity credential types. Applications with a separate
  Azure.Identity reference should remove versions older than 1.21.0 or upgrade to 1.21.0
  or later; Azure.Identity.Broker users need 1.6.0 or later.
- Existing async provider APIs do not imply that the driver uses them on async command
  execution. That integration remains open in 8.1.0-preview1, outside this milestone.
  ([#4585](https://github.com/dotnet/SqlClient/pull/4585))

## Target Platform Support

- Package asset: .NET Standard 2.0.
- With the 8.0 driver: .NET Framework 4.6.2+ on Windows, or .NET 10.0+ on Windows,
  Linux, and macOS.
