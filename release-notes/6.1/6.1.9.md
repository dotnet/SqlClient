# Release Notes

## Planned Stable Release 6.1.9 - Unreleased

These notes describe changes currently merged into `release/6.1` for the
[6.1.9 milestone](https://github.com/dotnet/SqlClient/milestone/112).
The release has not been published; the date and final package contents are not yet established.
The branch's `MdsVersionDefault` still reads `6.1.8`, so `6.1.9` is the planned milestone version,
not a verified published package version.

## Changes Since [6.1.8](6.1.8.md)

### Fixed

- Fixed corrupted `nvarchar` text from `SqlDataReader.GetTextReader` with
  `CommandBehavior.SequentialAccess` on big-endian platforms. Decoding now preserves the source
  buffer, raw UTF-16 code units, offsets, and partial reads. Little-endian behavior is unchanged.
  (big-endian only)
  ([#4945](https://github.com/dotnet/SqlClient/pull/4945),
  [#4963](https://github.com/dotnet/SqlClient/pull/4963))

- Fixed malformed row, alternate-result, and authentication responses being processed without
  required metadata or authentication state. These responses now produce the existing
  corrupted-stream parsing error (`InvalidOperationException`) and invalidate the physical
  connection so it cannot return to the pool. Valid SQL Server result processing is unchanged.
  ([#4941](https://github.com/dotnet/SqlClient/pull/4941),
  [#4981](https://github.com/dotnet/SqlClient/pull/4981))

## Target Platform Support

- .NET Framework 4.6.2+ (Windows x86, Windows x64, Windows ARM64)
- .NET 8.0+ (Windows x86, Windows x64, Windows ARM64, Linux, macOS)
- `netstandard2.0` reference/fallback assets do not expand supported driver runtimes.
